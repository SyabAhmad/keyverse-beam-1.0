# Taste
- Prefers React, TypeScript, and Three.js for interactive 3D web experiences. Confidence: 0.95
- Prefers real 3D geometry with accurate raycasting or equivalent hit areas for interactive 3D objects. Confidence: 0.9
- Prefers genuine real-time 3D animation with camera choreography and seamless transitions over static mockups, popups, or page reloads. Confidence: 0.9
- Prefers no external API dependencies or paid services; audio should be synthesized or locally generated. Confidence: 0.95
- Prefers no audio autoplay before user interaction and a visible mute toggle. Confidence: 0.9
- Prefers performance-conscious 3D implementation: efficient particles/instancing, adaptive counts, lazy initialization, resource disposal, resize/device-pixel-ratio/mobile handling, WebGL fallbacks, and reduced-motion support. Confidence: 0.9
- Prefers minimal, cinematic UI with high-quality typography and physically inspired materials; avoid excessive panels, generic card layouts, random spinning objects, abrupt cuts, and distracting effects. Confidence: 0.85
- Prefers implementing complete, working experiences rather than stopping at plans, wireframes, static renderings, or simple prototypes. Confidence: 0.9
- Prefers verifying implementations by running the app and production build, testing interactions, checking console errors/resource cleanup, and honestly reporting incomplete features. Confidence: 0.9
